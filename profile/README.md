**Creating a EVM native and decentralized agent layer**

At Drosera, we are building a decentralized agent layer for the EVM that enables developers to create **Traps** — smart contracts that monitor on-chain data and trigger automated on-chain responses. By leveraging the **Drosera Protocol** and a network of **Operators**, we aim to provide a scalable, trustless framework for DeFi security, general automation and cost efficient Dapps.

> “Orange is the New Stack.” — Programming Ethereum to Think and React.

## How It Works

At the heart of Drosera are two components:

| Primitive      | Purpose                                                        |
|----------------|----------------------------------------------------------------|
| **Trap**       | Smart contracts that monitor on-chain activity and decide when a response is needed. |
| **Operator**   | Permissioned or public nodes that execute responses defined by Traps. |


Drosera transforms static smart contracts into dynamic with these components, responsive systems that can:

- **Defend autonomously** against sophisticated attacks  
- **Trade intelligently** with complex, multi-step strategies  
- **Govern dynamically** based on real-time protocol health  
- **React instantly** to player actions and game state changes  
- **Coordinate seamlessly** across protocols, chains, and applications

Traps don't just react to immediate on-chain events. They can process historical blockchain data, perform time-series analysis, and make decisions based on complex patterns across multiple variables and timeframes. It's like giving your smart contracts the ability to learn from experience.

##  Use Cases

Drosera enables powerful DeFi security applications, including:
- **Treasury Management**: Monitor funds and trigger emergency responses if unauthorized transfers occur.
- **Lending Platforms**: Detect low collateralization ratios and automate liquidation alerts.
- **Decentralized Exchanges**: Identify unusual trading activity or market manipulation.
- **Time-Series Analysis**: Analyze historical on-chain data to detect patterns like vesting schedules or debt-to-collateral ratios.


##  Why Drosera

- **Trustless & Decentralized**: No single entity controls the network—Operators and Traps work together to ensure security.  
- **Developer-Friendly**: Simple APIs and templates make Trap creation accessible.  
- **Ethereum-Native**: Built for seamless integration with Ethereum and EigenLayer’s restaking.  
- **Community-Driven**: Collaborate with a passionate community to innovate DeFi security.

  

## Key Repositories

Explore our open-source projects to start building with Drosera:

- [**drosera-network/examples**](https://github.com/drosera-network/examples)  
  A collection of example **Drosera Traps** in Solidity, showcasing how to detect incidents (e.g., balance drops, liquidity issues) and integrate with the Drosera Protocol. Perfect for developers learning Trap creation!

- [**drosera-network/trap-foundry-template**](https://github.com/drosera-network/trap-foundry-template)  
  A Foundry template to kickstart your Drosera Trap development. Run the following command to set up a new project:  
  `forge init -t drosera-network/trap-foundry-template`

- [**drosera-network/releases**](https://github.com/drosera-network/releases)  
  Official releases for the Drosera CLI and Nodes (e.g., v1.19.0). Download and run Operator nodes to execute Traps and earn rewards.

- [**drosera-network/erc7579-trap-integration-poc**](https://github.com/drosera-network/erc7579-trap-integration-poc)  
  Our proof-of-concept for integrating smart-contract accounts with Traps to enable autonomous wallets.
